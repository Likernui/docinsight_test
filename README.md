# DocInsight

Десктопное приложение для извлечения сущностей и семантического поиска по корпусу документов.

## Назначение

Автоматическое извлечение структурированных данных (ФИО, научные руководители, источники, технологии и др.) из документов:
- Отчёты (DOCX)
- Документы (PDF)
- Сканы (PNG, JPG)

```bash
pip install -r requirements.txt
```

## Техническое задание

### Общее описание

**DocInsight** — десктопное приложение для автоматической обработки, анализа и семантического поиска по корпусу учебных и проектных документов (отчёты, пояснительные записки, PDF, сканы).

**Цель:** Пользователь загружает пачку документов → приложение извлекает текст → очищает → разбивает на фрагменты → находит сущности (имена, технологии, руководители) → позволяет искать по смыслу, а не по ключевым словам → формирует итоговый отчёт.

### Архитектура

```
Загрузка документов (text_extractor.py)
         ↓
Предобработка (preprocessor.py)
         ↓
Векторный индекс (indexer.py)
         ↓
Семантический поиск (semantic_search.py)
         ↓
Извлечение сущностей (entity_extractor.py) ← GLiNER
         ↓
Агрегация (aggregator.py)
         ↓
Генерация отчёта (result_generator.py)
```

### Зависимости

| Библиотека | Версия | Назначение |
|-----------|--------|-----------|
| `PyQt6` | >=6.4.0 | GUI |
| `python-docx` | >=0.8.11 | Чтение DOCX |
| `PyMuPDF` | >=1.21.0 | Чтение PDF |
| `easyocr` | >=1.7.0 | OCR изображений |
| `sentence-transformers` | >=2.2.0 | Эмбеддинги для поиска |
| `faiss-cpu` | >=1.7.4 | Векторный индекс |
| `gliner` | >=0.2.0 | NER (извлечение сущностей) |
| `transformers` | >=4.30.0 | ML backend для GLiNER |
| `torch` | >=2.0.0 | ML backend |

### Пайплайн обработки

1. Пользователь выбирает файлы (.docx, .pdf, .png, .jpg)
2. **text_extractor.py** — извлечение сырого текста
3. **preprocessor.py** — очистка + разбиение на чанки
   - DOCX: структурное разбиение по заголовкам
   - PDF: по предложениям
   - Overlap: 2 последних предложения
4. **indexer.py** — векторизация чанков (sentence-transformers → FAISS)
5. Пользователь вводит запрос → **семантический поиск**
6. **entity_extractor.py** — GLiNER извлекает сущности (планируется)
7. **aggregator.py** — объединение результатов (планируется)
8. **result_generator.py** — генерация DOCX-отчёта (планируется)

### Ключевые требования к обработке текста

- Чанки — только целые предложения, без обрывков слов
- Overlap — 2 последних предложения (настраиваемо 0-5)
- DOCX — структурное разбиение по заголовкам, чанки не пересекают секции
- PDF — разбиение по предложениям, целые фразы
- Средний размер чанка: 400-600 символов
- Извлечение сущностей — GLiNER zero-shot, 6 типов: человек, должность, технология, организация, проект, дата
- Семантический поиск — по смыслу, не по ключевым словам

## Реализованный функционал

### ✅ text_extractor.py — Извлечение текста

**DocxExtractor:** параграфы, таблицы, колонтитулы, сноски
**PdfExtractor:** постраничное извлечение через PyMuPDF
**ImageExtractor:** OCR через EasyOCR (ru+en)
**DocumentLoader:** автоопределение формата, пакетная загрузка, callback прогресса

### ✅ preprocessor.py — Предобработка текста

**TextCleaner:** склеивание переносов, схлопывание пробелов, нормализация
**DocxSectionParser:** структурный анализ DOCX по заголовкам (Heading 1/2/3)
**StructuralChunker:** разбиение по предложениям, overlap = целые предложения
**TextPreprocessor:** пайплайн очистка → chunking

### ✅ indexer.py — Векторный индекс

**Vectorizer:** sentence-transformers (paraphrase-multilingual-MiniLM-L12-v2), ленивая загрузка + кэш
**VectorIndex:** FAISS IndexFlatIP (косинусное сходство), save/load
**IndexBuilder:** чанки → векторизация → FAISS

### ✅ semantic_search.py — Семантический поиск

**SearchResult:** структура результата (текст, файл, score, метаданные)
**SemanticSearch:** поиск по индексу, группировка по файлам, контекст соседних чанков

## Тестирование

### GUI для тестирования (`test_gui.py`)

- Выбор нескольких файлов одновременно (без дубликатов)
- Загрузка файлов → извлечение текста → предобработка → индексация
- Настройка параметров предобработки (размер чанка, overlap)
- Просмотр всех чанков с прокруткой
- Семантический поиск по запросу (Enter или кнопка)
- Результаты поиска с score и подсветкой
- Статистика по файлам и чанкам

### Консольный тест (`test_document_loader.py`)

- Автоматическая проверка всех форматов
- Вывод статистики по каждому файлу
- Тестирование OCR функциональности
