# DocInsight

Десктопное приложение для извлечения сущностей и семантического поиска по корпусу документов.

## Назначение

Автоматическое извлечение структурированных данных (ФИО, научные руководители, источники, технологии и др.) из документов:
- Отчёты (DOCX)
- Документы (PDF)
- Сканы (PNG, JPG)

## Установка

```bash
pip install -r requirements.txt
```

## Запуск тестов

### Консольный тест
```bash
python test_document_loader.py
```

### GUI тест
```bash
python test_gui.py
```

## Реализованный функционал

### ✅ Пункт 2.1: Извлечение текста из DOCX и PDF

**DocxExtractor:**
- Извлечение текста из параграфов
- Извлечение текста из таблиц
- Извлечение текста из колонтитулов (header/footer)
- Извлечение текста из сносок (footnotes)

**PdfExtractor:**
- Извлечение текста постранично
- Использование библиотеки PyMuPDF

### ✅ Пункт 2.2: OCR для сканированных документов

**ImageExtractor:**
- Распознавание текста с изображений
- Поддержка множественных языков (ru, en по умолчанию)
- Ленивая загрузка OCR модели
- Использование библиотеки EasyOCR

### ✅ DocumentLoader

- Автоматическое определение формата файла
- Поддержка форматов: `.docx`, `.pdf`, `.png`, `.jpg`, `.jpeg`
- Загрузка одного файла или пакетная загрузка
- Обработка ошибок без прерывания процесса
- Callback для отображения прогресса

## Тестирование

### GUI для тестирования (`test_gui.py`)

- Выбор нескольких файлов одновременно
- Загрузка файлов по одному (накопительный режим)
- Просмотр полного текста каждого файла
- Переключение между файлами через выпадающий список
- Статистика по всем файлам (символы, слова, строки)
- Индикация прогресса обработки

### Консольный тест (`test_document_loader.py`)

- Автоматическая проверка всех форматов
- Вывод статистики по каждому файлу
- Тестирование OCR функциональности
